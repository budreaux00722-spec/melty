# Credits

**Scrap Sky** by budreaux00722, built with Claude Code. Code: MIT (see LICENSE).

## Games (not included: each player's own copy is read at runtime)
- **Minecraft: Java Edition** by Mojang Studios: the world it plays in. Not an official Minecraft product; not approved by or associated with Mojang or Microsoft.
- **Scrap Mechanic** by Axolot Games: part names, textures and colours, read from the player's install.
- **No Man's Sky** by Hello Games: soundtrack, planet descriptors and the words planet names are generated from, read from the player's install.

No file from any of these games is shipped with Scrap Sky.

## Bundled software
- **Prism Launcher** (GPL-3.0), https://prismlauncher.org: portable launcher the release ships unmodified; its source is at https://github.com/PrismLauncher/PrismLauncher.
- **Fabric Loader** (Apache-2.0) and **Fabric API** (Apache-2.0), https://fabricmc.net.
- **e4mc** by Skye (MIT), https://github.com/vgskye/e4mc-minecraft-architectury: lets friends join without port forwarding.
- **aircompressor** by the Airlift project (Apache-2.0): zstd decompression for No Man's Sky's archives.
- **ww2ogg** by Adam Gashlin, with Xiph.org code (BSD, see assets/scrapsky/ww2ogg/COPYING): Scrap Sky's Wwise-to-Ogg converter is a Java port of it, and its packed codebook files are included.
